# Konstrukt

Простий статичний веб-проєкт з файлів `index.html` і `style.css`.

## Опис

Цей репозиторій містить мінімальний приклад веб-сторінки і стилі для неї. Використовується для демонстрації структури проєкту та швидкого прототипування.

## Вміст

- `index.html` — основна HTML-сторінка.
- `style.css` — таблиця стилів для сторінки.

## Вимоги

- Будь-який сучасний веб-браузер (Chrome, Edge, Firefox, Safari).

## Запуск

1. Відкрийте файл `index.html` у браузері (подвійний клік або `Ctrl+O` → виберіть файл).
2. Для локальної розробки можна використовувати простий HTTP-сервер, наприклад:

```bash
# Python 3.x
python -m http.server 8000

# Потім відкрити http://localhost:8000
```

## Розробка

- Змінюйте `index.html` та `style.css` і оновлюйте сторінку в браузері.
- Рекомендовано використовувати Live Server або інший інструмент для автоматичного перезавантаження.
